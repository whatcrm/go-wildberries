# go-wildberries

![Wildberries API Library](wildberries-logo.png)

**go-wildberries** is a Rest API for [Wildberries](https://dev.wildberries.ru/). You can manage
your application with this library. It contains multiple
API requests Wildberries Seller provides with support of CRUD operations.

## Quick Start / Installation

To get started with **go-wildberries**, you'll need to do the following:

- Install the latest version of Go.
- Install the **go-wildberries** package using go get.
- Use the **go-wildberries** package in your Go code.
- Here's an example of how to install the package:

```
go get github.com/whatcrm/go-wildberries
```

## Models

**go-wildberries** includes a package for working with models, which allows you to use just the API and **create your own models**.
This means you can create your own structs and use them with our **go-wildberries** package,
even if you don't want to use every field from Wildberries' entities.

Here's the link to [Models](https://github.com/whatcrm/go-wildberries/models) package and example of how to install the package.

```
go get github.com/whatcrm/go-wildberries/models
```

## Features

- *Lightweight and easy-to-use*
- Simple and efficient net/http solution
- Comprehensive **CRUD** for working with Wildberries
